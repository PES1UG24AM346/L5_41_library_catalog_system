# Static Code Analysis Issues

The following issues were identified across the codebase using Bandit, Pylint, and Flake8 static analysis tools. High and medium severity issues are prioritized first.

| Issue | Type | Line(s) | Description | Fix Approach |
|-------|------|---------|-------------|--------------|
| Command Injection via `os.system` (Bandit B605) | Security (High) | 58 | Starting a process with a shell using `os.system()` with string concatenation (`"echo Catalog backup exported to: " + filename`) introduces a potential shell injection vulnerability if untrusted input is passed. | Remove `os.system()` and use Python's built-in `print()` function directly (e.g., `print(f"Catalog backup exported to: {filename}")`), or use `subprocess.run()` with argument lists and `shell=False`. |
| Weak Cryptographic Hash Function MD5 (Bandit B324) | Security (High) | 47 | Use of `hashlib.md5()` for hashing patron IDs. MD5 is cryptographically weak, broken, and susceptible to collision attacks. | Replace `hashlib.md5()` with a secure cryptographic hashing algorithm such as `hashlib.sha256()`. |
| Arbitrary Code Execution via `eval()` (Bandit B307, Pylint W0123) | Security (Medium) | 42 | Using `eval(calc_expr)` dynamically executes arbitrary Python code from string expressions, which poses a severe security risk if user input is supplied. | Avoid dynamic evaluation entirely by implementing explicit arithmetic calculations (e.g., `days_overdue * rate`), or safely parse literals using `ast.literal_eval()` if necessary. |
| Mutable Default Argument (Pylint W0102) | Bug Risk / Code Quality (Medium) | 15 | `issueBook` defines `active_issues=[]` as a default parameter. Mutable default arguments are evaluated only once at function definition, leading to shared state and unintended side effects across multiple calls. | Replace the default argument with `None` (`active_issues=None`) and initialize a new list inside the function body if `active_issues is None`. |
| Bare `except` with Silent `pass` (Bandit B110, Flake8 E722, Pylint W0702) | Error Handling / Bug Risk (Low) | 26–27 | A bare `except:` block combined with `pass` suppresses all exceptions silently (including `KeyError`, `KeyboardInterrupt`, and `SystemExit`), concealing runtime errors and complicating debugging. | Catch specific exceptions such as `except KeyError:` and provide appropriate error handling or logging rather than silently passing. |
| Unused Import `csv` (Flake8 F401, Pylint W0611) | Code Quality / Style (Low) | 6 | The module imports `csv` (`import csv`), but the module is never used anywhere in `library_catalog_system.py`. | Remove the unused `import csv` statement to keep the namespace clean and improve code readability. |
